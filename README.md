# Auto MPG Fuel Consumption Prediction

A beginner machine learning project that predicts a car's fuel efficiency in miles per gallon (MPG) using linear regression.

## Dataset
[Kaggle: Auto MPG Dataset](https://www.kaggle.com/datasets/uciml/autompg-dataset)

## Features
The model uses vehicle specifications such as weight, horsepower, displacement, cylinders, acceleration, and model year.

## Tools
- Python
- Pandas
- Scikit-learn
- Gradio
- Google Colab

## Run
Open the notebook in Google Colab and run the cells in order. The notebook trains the regression model and launches a Gradio interface for predictions.

## Note
This is an educational project. Model predictions are estimates and depend on the dataset and input values.
